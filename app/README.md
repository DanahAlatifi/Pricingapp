# تطبيق تسعير (Expo)

تطبيق الجوال — React Native + Expo. يربط بالسيرفر الوسيط الذي يربط بدوره بأودو.
يغطي **المرحلة ١ + ٢**: تسجيل الدخول، الرئيسية، الطلبات، تفاصيل العرض، طلب جديد/تعديل، الملف الشخصي.

## التشغيل

```bash
cd app
npm install
npm start          # ثم امسح QR من تطبيق Expo Go على جوالك
```

## ⚠️ مهم جداً: عنوان السيرفر (للجوال الحقيقي)

التطبيق على جوالك **لا يستطيع** الوصول إلى `localhost` لأن `localhost` تعني الجوال نفسه.
لازم تستخدم **عنوان IP المحلي لجهاز الكمبيوتر** الذي يشغّل السيرفر.

١. اعرف IP جهازك:
- ويندوز: `ipconfig` → ابحث عن IPv4 (مثل `192.168.1.10`)
- ماك/لينكس: `ifconfig | grep "inet "` أو `ip addr`

٢. عدّل العنوان في `app.json`:
```json
"extra": { "apiBaseUrl": "http://192.168.1.10:3000" }
```
(غيّر `192.168.1.10` لـ IP جهازك، وأبقِ المنفذ `3000`)

٣. تأكد أن الجوال والكمبيوتر **على نفس شبكة الواي‑فاي**.

٤. تأكد أن السيرفر شغّال (`cd server && npm run dev`).

> نصيحة: لو ما اشتغل الاتصال، جرّب توقف الجدار الناري (firewall) مؤقتاً على جهازك،
> لأنه أحياناً يمنع الجوال من الوصول للمنفذ ٣٠٠٠.

## الخط العربي

التطبيق يستخدم خط **IBM Plex Sans Arabic** (نفس الموك‑أب).
حمّل الملف وضعه هنا: `app/assets/IBMPlexSansArabic-Regular.ttf`
- من: https://fonts.google.com/specimen/IBM+Plex+Sans+Arabic
- لو لم تضعه، يعمل التطبيق بالخط الافتراضي للنظام بدون أخطاء.

## RTL
التطبيق يفعّل RTL تلقائياً عند أول تشغيل. لو ظهرت الواجهة بالاتجاه الخطأ
أول مرة، أغلق التطبيق وافتحه من جديد (forceRTL يحتاج إعادة تشغيل واحدة).
